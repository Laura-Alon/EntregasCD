### 2. Describe, para la clase Libro, qué debería ocurrir cuando se intenta prestar un ejemplar: qué se comprueba antes de prestarlo y qué cambia en el objeto si el préstamo tiene éxito o si no lo tiene

Para la clase Libro, primeramente se debe conocer el libro deseado y comprobar si hay ejemplares disponibles.
**Si hay ejemplares disponibles** (i.e. nº ejemplares disponibles >= 1): se descuenta un (1) ejemplar disponible y se crea el Préstamo, indicando el Libro y el Socio, así como la fecha de inicio del préstamo. Préstamo exitoso.
    *→ cuando el préstamo se devuelva, se modificará la fecha devolución préstamo (Préstamo) y el nº de ejemplares disponibles (Libro).*
**Si no hay ejemplare disponibles** (i.e. nº ejemplares disponibles = 0): imposibilidad de préstamo ya que no hay ejemplares disponibles. No se modificaría el número de ejemplares ni se crearía Préstamo. Préstamo no exitoso.
